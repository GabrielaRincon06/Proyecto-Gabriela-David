# README - Estimador de Costos de Software

## Descripción del Proyecto

Este proyecto consiste en el desarrollo y maquetación del front-end de una plataforma web interactiva orientada a la estimación de costos de proyectos de software.

La aplicación fue construida utilizando únicamente HTML5 y CSS3 nativo, enfocándose en la experiencia de usuario (UX) y el diseño de interfaces modernas (UI). El sistema simula visualmente un flujo de cotización de proyectos mediante distintas vistas y componentes interactivos, sin implementar lógica funcional con JavaScript.

El objetivo principal es ofrecer una experiencia visual profesional que permita al usuario recorrer un proceso de estimación de costos de manera intuitiva, clara y responsive.

---

# Objetivos

- Diseñar una interfaz moderna y profesional para estimar costos de proyectos de software.

- Implementar estilos avanzados con CSS3 puro.

# Responsive Design

El proyecto fue desarrollado bajo metodología **Mobile First**, garantizando adaptación correcta en:

- Dispositivos móviles
- Tablets
- Pantallas de escritorio

Se implementaron `@media queries` para ajustar:
- Distribución de elementos
- Tamaños de texto
- Espaciados
- Organización de tarjetas y formularios
